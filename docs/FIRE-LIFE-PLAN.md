# FIRE 生活规划书

> 这份文档回答四个问题：**FIRE 后在哪生活、住什么样的房子、每天吃什么、不交社保怎么看病**。
> 它的输出是一个可追溯的「月开销」，而这个数字会直接决定 [README](../README.md) 上的 FIRE 目标。
>
> **所有金额都不是手算的**——它们来自 [`config.yaml`](../config.yaml) 的 `life_plan` 段，
> 由 `scripts/lifeplan.py` 汇总。改一项，FIRE 目标自动重算。

## 2. 城市选择

### 2.1 候选城市对比

> **鹤岗的 87% 计费是个容易漏掉的细节**：一套 100㎡ 的房子，实际只按 87㎡ 收钱，
> 年取暖费 ¥2,392.5。折算下来单价其实低于长春、大连。

### 2.2 为什么是鹤岗

1. **房价与租金都是候选里最低的**——租金只有伊春的 60%、大庆的一半。
2. **有三级甲等医院**（鹤岗市人民医院），常规看病不用外跑，这对不交社保的人尤其重要。
3. **供暖计费面积打 87 折**，取暖费实际低于多数东北城市。
4. **落户与购房政策宽松**，新市民有配套支持，异地定居的摩擦小。
5. 生活便利度不差：连锁超市、外卖、公交（¥1 全程、月卡 ¥50）都有。

### 2.3 为什么不选伊春

伊春的居住环境（森林、空气）优于鹤岗，是很好的备选。但**房价约为鹤岗的 2.4 倍**
（¥5,004 vs ¥2,083），折算到 50㎡ 月租约 ¥851，比鹤岗高 ¥340/月。

按 4.3% 提取率反推，这 ¥340/月 意味着 **FIRE 目标要多约 ¥95,000**。
如果愿意为环境付这个溢价，把 `config.yaml` 里的房租项改成 ¥860 即可，其余自动重算。

### 2.4 为什么不选省会

沈阳/长春/哈尔滨的医疗、教育、交通明显更好，但房价是鹤岗的 4 倍左右。
省会方案的月开销大致会落在 ¥3,000–3,500，对应 FIRE 目标 **¥840,000–980,000**——
比鹤岗方案多出一倍。在资产规模还只有 ¥14k 的现阶段，这个差距不是「忍一忍」能填平的。

> 顺带一提：哈尔滨的取暖费（¥38.32/㎡）是东北省会里最高的，选省会时这是笔不小的固定成本。

## 3. 住房选择

### 3.1 租房方案（当前采用）

| 项目 | 金额 | 依据 |
| --- | ---: | --- |
| 房租 | ¥520/月 | 一居室/简装小两居（老城区）。鹤岗住宅均价 ¥2,083/㎡、售租比 17，折算 50㎡ 月租约 ¥500–620 |
| 取暖费 | ¥100/月 | 集中供暖，¥27.5/㎡ × 87% 计费面积 × 50㎡ ÷ 12 ≈ ¥100 |
| 物业费 | ¥20/月 | 老旧小区约 ¥0.4/㎡/月；部分小区由财政兜底 |
| 水费 | ¥12/月 | 单人约 3 吨 |
| 电费 | ¥55/月 | 约 110 度。冬季靠集中供暖，**不需要电暖器**，用电量远低于南方 |
| 燃气/液化气 | ¥35/月 | 约 1/3 罐 15kg 液化气 |
| 家电维修与更换摊销 | ¥40/月 | 洗衣机、冰箱等按 10 年更换摊销，含小修。租房通常需自备 |

### 3.2 取暖费：东北特有的固定成本

这是北方 FIRE 预算里最容易被南方经验漏掉的一项。它的特点是：

- **不可选、不可省**——冬天不交取暖费就是没暖气，鹤岗冬季最低气温可达 −30℃。
- **按面积收**，所以住得越大越贵，与「极简」的省钱方向天然冲突。
- **按采暖季一次性缴**（通常 9–10 月），不是按月扣。做现金流时要单独留出这笔钱。

> **租房时谁交取暖费，必须在合同里写清楚。**
> 东北的租房市场上两种都有：有的房东包取暖费（租金已含），有的明确「取暖费自理」。
> 本规划按**租客自付**建模——这是保守假设，如果房东包，实际月开销会低 ¥100。

### 3.3 租房注意事项

- **冬季看房**：一定要在供暖季实地看一次，确认室温与供暖是否达标。夏天看房看不出供暖问题。
- **老城区步梯房**：鹤岗低价房源多是 10 年以上房龄的步梯房，低楼层/顶楼的采光与保温要重点看。
- **警惕超低价房源**：网上流传的「5 万一套」多在偏远矿区，没公交、没超市、供暖还不好。
  真正能日常居住的，刚需款大致 ¥15 万起。
- **供暖费、物业费、水电燃气由谁承担**——逐项写进合同，别口头约定。

### 3.4 租 vs 买：算一遍

这是本规划里最值得算清楚的一件事，因为结论不直观。

**判据**：把买房看成「花一笔钱，买断未来的房租」。这笔钱的隐含回报率 = `净省下的房租 ÷ 购房投入`。
再拿它和提取率（4.3%）比——高于 4.3% 才说明买房划算。

| 方案 | 月开销 | FIRE 目标 | 一次性支出 | **合计资金需求** |
| --- | ---: | ---: | ---: | ---: |
| 租房（当前） | ¥1,620 | ¥452,093.02 | ¥15,000 | **¥467,093.02** |
| 买房（40㎡ 老城区二手房） | ¥1,290 | ¥360,000.00 | ¥102,000 | **¥462,000.00** |

买房方案的口径（**必须和租房同面积**，否则是苹果比橘子）：
- 房款 ¥85,000（40㎡ × ¥2,100/㎡）+ 契税与过户约 ¥3,000
- 月开销 = ¥1,620 − ¥430（不再付房租）+ ¥100（维修与大修摊销）= ¥1,290
- 一次性支出 = ¥85,000 + ¥3,000 + ¥8,000（家具家电）+ ¥3,000（搬家）+ ¥3,000（过冬装备）= ¥102,000

**隐含净回报率 = (¥5,160 年省租金 − ¥1,200 年维修) ÷ ¥88,000 = 4.50%**

4.50% 只比提取率高 0.2 个百分点，**买房略优，合计资金需求少约 ¥5,093（1.1%）**——
薄到基本可以忽略。

> ⚠️ **把房租压下来，会削弱买房的优势。**
> 优化前房租 ¥520、对应 50㎡ 的房子 ¥105,000，隐含回报率是 **4.67%**；
> 现在房租 ¥430、对应 40㎡ 的房子 ¥85,000，回报率掉到 **4.50%**。
> 原因是**维修摊销 ¥1,200/年是固定成本**，不随面积缩小——
> 房子越小，它占净收益的比例越大。**房子越小，买房越不划算。**

**这点微弱的优势还会被下面几件事吃掉：**

1. **房价正在下行**：鹤岗 2026-08 挂牌均价环比 −7.87%。跌 10% 买房会明显占优，
   但跌 20% 本金损失约 ¥17,000，远超省下的 ¥5,093。
2. **流动性极差**：鹤岗人口持续流出，房子可能挂很久卖不掉。租房可以随时换城市，买房不行。
3. **交易成本**：买入约 3%、卖出再 3%，一进一出约 ¥5,000+，**刚好把这 1.1% 的优势抹平**。
4. **机会成本**：¥88,000 一次性支出后就不再产生现金流。而租房方案里，
   这笔钱是 FIRE 组合的一部分，每年产出约 ¥3,784（按 4.3%）。
5. **本模型没算房价升值**——在人口流出的城市里，长期升值假设本身就不成立。

**结论：现阶段按租房建模。** 理由是「不锁死本金 + 保留换城市的自由」，
而买房在财务上已经**没有实质优势**（¥5,093 / 1.1%，还在交易成本的误差范围内）。
在资产还只有 ¥14k 的阶段，灵活性显然更值钱。

> **切换方式**：等真到了要做决定的时候，如果鹤岗房价继续下跌、或你确定要长期安定下来，
> 把 `config.yaml` 里的 `housing` 改成 `buy`、房租项换成维修摊销项，目标会自动重算。
> 注意**两条腿都要动**（去掉房租 + 加上维修），只改一条会得到错误结果。

## 4. 每天饮食安排

### 4.1 原则

1. **早市优先**。鹤岗早市菜价比超市低约 30%（例：黄瓜早市 ¥1.5/斤，超市 ¥2.5/斤），
   且早上 6–8 点去最新鲜。这是食品预算能压到 ¥500/月 的关键。
2. **一次多做、分次吃**。炖菜（白菜炖豆腐、土豆炖牛肉、酸菜炖粉条）做一锅吃两天，
   省燃气也省时间。
3. **跟着季节走**。夏天蔬菜便宜，冬天靠囤菜与腌菜。
4. **自己做饭为主，每月留 ¥50 偶尔外食**——极简不等于苦行。

### 4.4 东北特有的季节性问题：囤冬菜

**10 月下旬**是冬菜上市季，这一个月把冬天的菜买齐，能显著压低 12 月–次年 3 月的食品支出：

- **大白菜**：约 ¥0.4–0.8/kg，买 100 斤（50kg）≈ ¥30，一部分鲜储、一部分腌酸菜
- **土豆、萝卜、大葱**：耐储，成袋买更便宜
- **腌酸菜**：自己腌一缸，冬天炖粉条、包饺子都用得上，成本远低于买成品

> 这一项没有单独建模（已包含在「食品 ¥500」里），但它是鹤岗生活成本能压到这么低的重要原因。
> 不会腌菜也没关系，冬季蔬菜靠外埠调运，价格会季节性上涨——所以 §7 的敏感性分析里
> 把月开销上浮到 ¥2,000 当作一个重要情景。

## 5. 医疗与保障（不交社保的完整路径）

不交社保是本规划里**风险最集中**的一环，需要单独设计。

### 5.1 不交社保意味着什么

| 失去的 | 后果 |
| --- | --- |
| 职工养老保险 | **没有养老金**，FIRE 组合是终身唯一的收入来源 |
| 职工医疗保险 | 报销比例更低、无个人账户、门诊统筹有限 |
| 生育/失业/工伤保险 | 与 FIRE 场景基本无关，可忽略 |

> ⚠️ **这是一个不可逆的决定，值得再确认一次。**
> 职工养老保险需累计缴满 15 年才能在退休后领取。现在不交，等于彻底放弃这条路径。
> 如果将来改变主意，缴费年限要重新起算（除非之前已有缴费记录）。

### 5.2 兜底方案一：城乡居民基本医疗保险

- **费用**：¥400/年（2026 年国家统一标准）= **¥33/月**
- **性质**：这是不交社保后**唯一的基础医保**，必须参保，不能裸奔
- **与职工医保的差距**：住院报销比例通常 50%–70%（职工医保约 80%–90%），
  没有个人账户返钱，门诊待遇也弱
- **结论**：能兜住「不至于因病返贫」，但兜不住「大病自付部分」，所以还需要下面两层

### 5.3 兜底方案二：龙江惠民保（补充医疗）

- **费用**：普惠版 ¥99/年、升级版 ¥150/年 = **约 ¥13/月**
- **特点**：政府指导、**不限年龄、无需健康告知、带病可保可赔**——这对将来年纪大了再投保特别重要
- **作用**：覆盖医保目录外的自费药与高值耗材，正好补上居民医保的短板
- **注意**：免赔额较高（通常万元以上），定位是「防大病」而不是「报小病」。
  每年保费与条款会调整，以当年官方发布为准

### 5.4 兜底方案三：医疗应急金（重要）

4.3% 提取率覆盖的是**日常**开销，覆盖不了「一次性大额医疗支出」。建议单列一笔专项：

- **金额建议**：¥50,000–100,000
- **不参与** `月开销 × 12 ÷ 提取率` 的计算，是独立于 FIRE 目标的一笔钱
- **放在哪**：货币基金 / 短债基金，随时可取，不要放进比特币或权益类
- **为什么必须有**：不交社保意味着没有单位补充医疗、没有工伤兜底，
  所有医疗风险都由自己承担

> 这笔钱**没有计入本文的 FIRE 目标**，所以实际需要的总资产应比 ¥452,093 更高。
> 建议在资产规模接近目标时，把这笔专项金一并纳入规划。

### 5.5 参保地问题（容易被忽略）

城乡居民医保按**户籍地或居住证所在地**参保。租房在鹤岗会遇到一个现实问题：

| 情况 | 做法 | 代价 |
| --- | --- | --- |
| 保留原户籍 | 在户籍地参保 | 异地就医需备案，报销比例可能再降 |
| 办鹤岗居住证 | 在鹤岗参保 | 需满足当地居住证办理条件（通常要求稳定住所+居住时间） |
| 落户鹤岗 | 在鹤岗参保 | 鹤岗落户政策宽松（凭房产证即可），但**租房落户需按当地政策核实** |

**务实建议**：先保留户籍地参保（最省事、不会断保），到鹤岗稳定居住后办居住证，
再评估是否转移。**不要出现断保**——城乡居民医保断缴后再参保通常有等待期。

### 5.6 值得考虑：城乡居民养老保险

「不交职工社保」不等于「完全没有养老兜底」。**城乡居民养老保险**是一条低成本路径：

- 年缴费可选档次（各地通常 ¥100–3,000 自选），缴满 15 年，60 岁后可领
  「基础养老金 + 个人账户养老金」
- 基础养老金由财政发放，标准各地不同，**具体金额需按参保地政策核实**
- 定位是「聊胜于无的兜底」，不能替代 FIRE 组合，但每年几百块的投入换来一份终身现金流，
  对不交职工社保的人来说性价比不低

> 是否参保由你决定。本文的 FIRE 目标**未包含**这项收入，属于保守处理——
> 如果将来参保并领取，实际需要的资产会比目标更低。

### 5.7 提取率要不要更保守？

**这是一个需要认真对待的问题。** 4.3% 这个提取率，通常建立在「有养老金作为底层现金流」的
假设上。而本规划的前提是**不交社保、没有养老金**：

- 组合是终身唯一收入来源，没有「领完了还有养老金」的兜底
- 医疗支出随年龄上升，而居民医保的报销比例低于职工医保
- 一旦组合大幅回撤且同时需要用钱，没有第二道防线

| 提取率 | 对应 FIRE 目标（月开销 ¥1,620） |
| --- | ---: |
| 3.5% | ¥555,428.57 |
| 4.0% | ¥486,000.00 |
| **4.3%（当前）** | **¥452,093.02** |
| 4.5% | ¥432,000.00 |

从 4.3% 收紧到 4.0%，目标要多约 ¥33,907（+7.5%）；收紧到 3.5%，要多约 ¥103,336（+22.9%）。

**建议**：现阶段保留 4.3%（资产规模还小，先把目标定在可触及的位置），
但在资产接近目标、真正要「按下按钮」之前，**重新评估一次提取率**——
那时才是这个决定真正产生后果的时候。

## 10. 怎么维护这份规划

所有金额都集中在 `config.yaml`，**改一处即可，FIRE 目标会自动重算**：

```yaml
life_plan:
  profile: hegang-rent-minimal   # ← 切换方案只改这一行
  profiles:
    hegang-rent-minimal:
      items:
        - {key: rent, ..., monthly: 520, ...}   # ← 改房租
```

改完必须跑测试（口径错了不会报错，只会让目标悄悄跑偏）：

```bash
python tests/test_life_plan.py    # 生活规划口径（26 项）
python tests/test_commit_gate.py  # 提交门控（14 项）
```

`tests/test_life_plan.py` 钉住了几条关键性质，其中最重要的一条是
**「一次性支出不得摊进月开销」**——这条一旦被改坏，FIRE 目标会被静默虚增。

若只想临时试算「如果每月花 ¥3,000 会怎样」，不必改明细，直接在 `config.yaml` 里填：

```yaml
fire:
  monthly_expense: 3000   # 填数字 = 覆盖 life_plan 的推导结果
```

README 会标注「当前为手工覆盖值」，不会把它误当成正式口径。试算完记得改回 `null`。
