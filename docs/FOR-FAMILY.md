我不是临时起意。这件事从 2026 年秋天开始就在一点点查、一点点记，
到现在有一份能逐项对账的计划，还有一张把每条依据都标了出处和日期的资料核对表。

## 1. 我想做的到底是什么

不是不工作，也不是不回来了。

毕业后，我打算先去一个生活成本低、安静的城市，自己租一间小房子，
找一份简单、规律、压力小的工作，自己做饭、自己过日子，过一段不靠家里的生活。
这段时间有多长不固定——**家里需要我的时候，我就回来。**

**有一件事我先说清楚：我没有在毕业前专门去那儿住过一趟。**
所以我不打算把「查过资料」说成「已经验证过」。落地后的第一个月就是用来逐项核实的，
因此先短租、不签长约，不合适就换，实在不行就回来。

我没有把这件事当成一辈子不挪窝的决定，所以它不需要赌，也不需要家里替我兜底。

## 2. 为什么是牡丹江

简单说三条：

- **回得来。** 有夕发朝至的普速列车，睡一晚就到，票价不高；
  真有急事，还有六小时出头的直达高铁。不是「去了就很难回来」的地方。
- **该有的都有。** 市区有四所三甲医院，是黑龙江东南部的区域中心城市，
  铁路、快递、商超、图书馆这些日常要用的东西都齐。
- **成本低、安静。** 房租和生活开销比北京低很多，城市不大，不堵车、不挤、不吵。
  租房我只挑**房租里已经包含取暖费和物业费**的房子，把冬天那笔固定开销锁死，
  签合同前会逐套确认、写进合同。

我也想把不好听的那半句一起说清楚：**那边发展机会少，年轻人往外走，
我不是去找事业、也不是去找高薪。** 我是主动把生活成本降下来，换一段清静日子。
这一点我没打算说服你们认同，只是不想让你们以为我在拿「有前途」当理由。

## 3. 我已经在做、并且能给你们看的事

| 时间 | 做的事 |
| --- | --- |
| 2026 年起 | 每个月记完整的收支账，和一份逐项写清楚的预算表对照；有固定的储蓄习惯，单独留着一笔应急的钱 |
| 大学期间 | 把当地政府发布的统计数据、供暖规定、最低工资、车票、租房信息逐条查清楚，标好出处和查的日期，做成一张核对表；每年重核一次，过期的就更新 |
| 大学期间 | 专业课没丢，保持能独立把项目做完的能力；不是为了去那边找对口工作，是给自己留一条退路 |
| 持续整理 | 毕业后的档案、户口、证件、组织关系、居住证、当地医保政策怎么办，列成一张清单，逐项查清楚怎么办、什么时候办 |
| **毕业后第一个月** | **先短租住下，不签长约。把供暖实际多少度、买菜方不方便、菜价、医院和火车站多远，逐项实测一遍，写成带日期的记录；不合适就换房，住不下去就回北京** |

这些不是为了说服谁写的，是我自己要用的。**要核哪一条，我可以把记录翻给你们看。**
还没核实的那几条，我也在清单里标着，不会当成已经办成的事讲。

## 4. 钱和保障怎么安排

- 开销按当地真实房源和物价**逐项算过**，不是拍一个数。预算表可以给你们看。
  其中房租这类价格来自租房平台，属于要落地再确认的，我会在签合同前逐套核一遍。
- **不向家里要钱**，也不把家里的钱和房子算进计划里。
- 留了三道缓冲：一笔随时能取的应急钱、一笔单独记账的医疗备用金、
  以及租房不买房——不把钱锁死，随时能改主意。
- 每年复核一次，物价和政策变了就跟着改，不是写完就不看了。

## 5. 什么时候回来，平时怎么联系

- **家里需要我，我就立刻回北京，之后不再回去。** 这不是计划失败，是本来就写好的结束条件。
  普速车睡一晚、高铁六小时，随时能走。
- 平时固定每周报一次平安，手机里设好紧急联系人；每年回北京一两次。
- 一个人住这件事我会认真对待：常用药备着、有事不硬撑、不舒服就联系你们。

## 6. 最后

我知道这个选择在你们看来不算「正经路子」。我不打算讲大道理说服你们，
只希望你们知道：**我不是一时冲动，也没打算一走了之。**
该查的我查了，该算的我算了，该留的退路我留了；
没查明白、没亲眼看过的地方，我写下来了，到那边第一个月就去核，核完告诉你们。

有什么担心，你们直接问，我一条一条答。
