### 外推

按「定投 + 资产增值」外推：日投 **¥60.12**（月 ¥1,803.50，比特币 6 USDT + 标普500 ¥20.00），叠加当前持仓按加权预期年化 **10.43%** 增长，**约 5.7 年**后达到**咖啡师 FIRE 门槛**（2032-08-03）。

> 区间：悲观约 8.1 年（加权 0.79%） · 基准约 5.7 年 · 乐观约 4.6 年（加权 20.80%）。
>
> 这不再是线性外推：定投按天累加，已有持仓按年化复利。差距全部来自收益率假设——比特币占七成时，「平均收益率」对这个组合没有实际意义，路径才重要，上沿只能当参考。
>
> 定投额用真实值、不用近 30 天增速：那段增速由行情主导，涨得快不等于进度快，跌的时候还会被推成「永远达不到」。
>
> **阶段 A 若有全职收入**（净 ¥2,739.33/月，盈余 ¥1,285.33 并入定投 → 月投 ¥3,071.22），同一口径下 **约 3.9 年**（2030-09-15）。这是敏感性测算，不是承诺——它假设这份工作从现在就有。

**主进度**默认用出发门槛（`display.primary_progress: departure`），以后要换只改 `config.yaml` 一行；三个门槛的金额、完成度和历史留档都不随开关变化。月开销由 `life_plan` 逐项相加，改一项三个门槛一起重算，依据见规划书 §6。

兼职净收入对应 `fire.labor_income`：FIRE 后继续做低压力、随时能停的兼职。只扣上班多出来的成本。把 `enabled` 改成 `false`，咖啡师 FIRE 门槛就与完全 FIRE 门槛相等（¥405,767.44）。

历次口径变更的日期、原因与对目标的影响集中记在 [CHANGELOG.md](docs/CHANGELOG.md)，这里不重复。**口径变更会让进度曲线出现台阶**：那是分母变了，不是资产涨了；`data/history.json` 逐日存了当时的 `target_cny` 与 `full_fire_cny`，可以查。

| 退出 | 长辈病情加重 → 回京，此后不再回来 | 长辈离世 → 继承 |

⚠️ 阶段 A **不指定工种**：「不局限于图书馆保安，
任何一个适合自己的轻松工作」都算。判据是工作性质（低内耗 / 坐岗 /
不轮岗 / 低人际 / 可随时停）+ 独自租房，不是岗位名字；图书馆只是候选之一。
¥17/h 是保守占位假设，换岗位按实际工资改 `config.yaml` 一行。
详见[路线图 §3.5.9](docs/FIRE-ROADMAP.md)。

阶段 A 有工资，所以**出发不需要攒够 ¥204,000.00**。真正的出发条件是**出发门槛 ¥54,362–108,724**（医疗应急 ¥5–10 万 + 空窗 3–6 个月，不含搬家/押金等一次性支出）。毕业时约 ¥9.4 万，取下沿够——所以出发时点从 2031-04 提前到 **2029-06 毕业当月**，而到达 ¥204,000.00 的时点几乎不变。这笔钱同时是失业缓冲：按 ¥1,454/月可撑约 65 个月。

找不到全职、只剩兼职时，按年金现值算（毕业时约 ¥9.4 万本金）：每周 3 天 × ¥15 可撑 **10.7 年**（到 32.7 岁），4 天 × ¥17 约 **79.8 年**（本金低于永续线 ¥97,116，属非永续）；分界线提前到外公约 88 岁，这件事无法提前知道。临界收益率分别是 9.36% 和 4.45%。以上按 4.3% 保守口径；按 7% 或加权预期年化 10.43%，4 天方案会回到永续（见路线图 §3.1）。

完整推演见 **[docs/FIRE-ROADMAP.md](docs/FIRE-ROADMAP.md)**。这一段不改变上面的目标与完成度，它回答的是另一个问题：这笔钱够不够撑到该回去的那天。

- ❌ 每月储蓄里转存的现金缓冲（约 ¥198/月）：按同一标准不计入分子，也不进外推。它是毕业时可动用的钱，见[路线图 §2.2](docs/FIRE-ROADMAP.md)

划线标准是「长期不动用」，不是「能不能变现」。所以**卖出后进度下跌未必是亏**，钱变成现金只是离开了这个范围。纳入标准的来由见[实现方案 §1.4](docs/DESIGN.md)，历次调整集中见 [CHANGELOG.md](docs/CHANGELOG.md)。

| 情形 | 进度 | 是否真实 |
| --- | --- | --- |
| 工资入金 / 买入 | ↑ | 真实增长 |
| 池内互换（卖 BTC 买标普500） | → 不变 | 正常 |
| 卖出后把钱花掉 | ↓ | 真实减少 |
| 卖出后变成现金放着 | ↓ | 假信号 |

> ⚠️ **配置偏斜**：比特币占七成以上，真正稳的标普500 只有四个点。纳指不算「稳」——它和标普相关性 0.9 以上，只是更偏科技、波动更大。`sp500_target_range` 目标是 25–30%，缺口在这里。占比只做展示、不影响目标，再平衡路径见[路线图 §2.3](docs/FIRE-ROADMAP.md)。

## 自动化

GitHub Actions 每小时轮询一次：读两个持仓仓库、抓行情和汇率、重算进度、更新本文件。结果没有实质变化就不提交，避免刷屏。

频率定得高，是因为 GitHub 的定时任务常比计划时间晚几小时触发。每小时跑一次，最大滞后约 1 小时。
