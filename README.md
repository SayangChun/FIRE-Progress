### 外推

按「定投 + 资产增值」外推：日投 **¥86.19**（月 ¥2,585.57，比特币 9.9 USDT + 标普500 ¥20.00），叠加当前持仓按加权预期年化 **10.45%** 增长，**约 4.4 年**后达到**咖啡师 FIRE 门槛**（2031-04-03）。

> 区间：悲观约 5.7 年（加权 0.77%） · 基准约 4.4 年 · 乐观约 3.6 年（加权 20.87%）。
>
> 这不再是线性外推：定投按天累加，已有持仓按年化复利。差距全部来自收益率假设——比特币占七成时，「平均收益率」对这个组合没有实际意义，路径才重要，上沿只能当参考。
>
> 定投额用真实值、不用近 30 天增速：那段增速由行情主导，涨得快不等于进度快，跌的时候还会被推成「永远达不到」。
>
> **阶段 A 若有全职收入**（净 ¥2,739.33/月，盈余 ¥1,278.33 并入定投 → 月投 ¥3,846.39），同一口径下 **约 3.2 年**（2030-01-24）。这是敏感性测算，不是承诺——它假设这份工作从现在就有。

## 两段式路线

上面两个 FIRE 门槛都是**永续**口径（资产不耗尽），实际计划是两段式：

| | 阶段 A | 阶段 B |
| --- | --- | --- |
| 地点 | **牡丹江** | 北京 |
| 性质 | 一个人租房住，不回家、不合住 | 回归家庭，看护长辈 |
| 收入 | 图书馆保安净 ¥2,739/月；找不到退回兼职 ¥723 | 无 |
| 退出 | 长辈病情加重 → 回京，此后不再回来 | 长辈离世 → 继承 |

阶段 A 有工资，所以**出发不需要攒够 ¥205,953**。真正的出发条件是**出发门槛 ¥56,183–110,566**（医疗应急 ¥5–10 万 + 搬家 ¥1,800 + 空窗 3–6 个月）。毕业时约 ¥10 万，取下沿够——所以出发时点从 2031-04 提前到 **2029-06 毕业当月**，而到达 ¥205,953 的时点几乎不变。这笔钱同时是失业缓冲：按 ¥1,461/月可撑约 68 个月。

找不到全职、只剩兼职时，按年金现值算（毕业时约 ¥11 万本金）：每周 3 天 × ¥15 可撑 **18.1 年**（到 40.1 岁），4 天 × ¥17 则**永续**；分界线是外公约 95 岁，这件事无法提前知道。临界收益率分别是 8.05% 和 3.80%。

完整推演见 **[docs/FIRE-ROADMAP.md](docs/FIRE-ROADMAP.md)**。这一段不改变上面的目标与完成度，它回答的是另一个问题：这笔钱够不够撑到该回去的那天。

划线标准是「长期不动用」，不是「能不能变现」。所以**卖出后进度下跌未必是亏**，钱变成现金只是离开了这个范围。纳入标准的来由与历史变更见[实现方案 §1.4](docs/DESIGN.md)。

| 情形 | 进度 | 是否真实 |
| --- | --- | --- |
| 工资入金 / 买入 | ↑ | 真实增长 |
| 池内互换（卖 BTC 买标普500） | → 不变 | 正常 |
| 卖出后把钱花掉 | ↓ | 真实减少 |
| 卖出后变成现金放着 | ↓ | 假信号 |

## 自动化

GitHub Actions 每小时轮询一次：读两个持仓仓库、抓行情和汇率、重算进度、更新本文件。结果没有实质变化就不提交，避免刷屏。

频率定得高，是因为 GitHub 的定时任务常比计划时间晚几小时触发。每小时跑一次，最大滞后约 1 小时。
